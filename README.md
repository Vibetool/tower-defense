# 飞碟塔防

three.js r147 + Kenney Tower Defense Kit / Skyboxes（CC0）。自己画地图、自己挑战；上帝视角和第一人称都能玩。

## 运行

GLB 模型要走 HTTP 载入，不能直接双击 html：

```bash
node tools/serve.mjs 8798
```

然后打开 http://localhost:8798/

## 玩法

- **地图编辑器**：格子上画道路（自动拼直路/弯道/三岔/十字）、塔位、起点（可多个）、终点（城堡，只有一个）、树/石头/水晶/小山装饰。可设尺寸、草地/雪地、天空、波数、初始金币、生命。地图存在浏览器 localStorage。
- **挑战**：飞碟从起点沿最短路飞向城堡。塔只能放在台子上：
  - 地图上的塔位 = 免费台子；
  - 草地上随便建台子：普通台子 30 金（卖 20），带炮台的台子 50 金（卖 35，中间伸出炮管，自己会转向开火，每 1 秒一发 22 伤害，射程 2.6，上面还能再放塔）；
  - 5 种塔（弩车/机枪塔/加农炮/投石车/冰晶塔）各 3 级，升级只涨数值、高度不变，台面上的小金块数 = 等级；卖塔退七成，拆台子连同上面的塔一起卖；
  - **第一波开始前卖任何东西都全额退款**。
  - 每 5 波来母舰。
- **视角**：V 键或右上角按钮切换。第一人称 WASD 走、Shift 跑、鼠标看，准星对准格子点左键打开面板，或按数字键直接建（草地上 1 台子 / 2 带炮台的台子，台子上 1-5 放塔）、U 升级；手机上左半屏摇杆、右半屏转头。

## 代码结构

| 文件 | 内容 |
| --- | --- |
| `js/defs.js` | 所有数值：塔、敌人、波次公式、编辑工具 |
| `js/maps.js` | 地图数据、道路自动拼接、BFS 路线、平滑曲线、存档、两张示例图 |
| `js/world.js` | 渲染器、天空盒、光照、静态地块（InstancedMesh 合批）、标记 |
| `js/input.js` | 上帝视角/第一人称相机与鼠标、触控、键盘 |
| `js/editor.js` | 地图编辑器 |
| `js/game.js` | 对战逻辑、弹道、特效、HUD、塔面板 |
| `js/main.js` | 首页、地图列表、结算、主循环 |

## 数值测试

改了 `defs.js` 的数值后，在页面控制台跑：

```js
eval(await (await fetch('tools/sim.js')).text()); TD_SIM.run()
```

会让一个简单的 AI 玩家用不同建塔策略把两张示例图各打一遍，输出每波剩余生命。跑完会写入通关记录，测完可以 `localStorage.removeItem('td_best_v1')`。
